# 科研论文辅助工作台 UI 视觉升级设计

日期：2026-07-13

## 目标

在不改业务逻辑与交互流程的前提下，将界面升级为 Notion 学术笔记风，并支持用户自选三套主题。

## 范围

### 做

- 顶栏轻重组：主操作 / 次要操作 / 主题切换
- 左栏论文列表更像笔记列表
- 中栏编辑区增加留白与阅读感
- 右栏质量面板更轻
- 三主题：冷蓝灰、暖纸感、深色护眼
- 主题偏好写入 localStorage

### 不做

- 导入 / 去重 / 证据等业务逻辑
- 快捷键与菜单能力变更
- 拖拽、新页面流等交互重构

## 方案

采用“文档页信息架构 + 主题 token”，不是只换配色：

1. 中栏改成 Notion 式文档页：大标题 + 属性板 + 分段正文，去掉双列 Card 表单
2. 左栏改成笔记列表：无卡片描边、弱筛选、行选中
3. 右栏改成轻检查器：去 Card 堆叠，改 inspector block
4. CSS 变量承载主题；Ant Design `ConfigProvider` 同步 primary / algorithm
5. 顶栏变薄，主操作 + 更多 + 主题切换

## 主题

| key | 名称 | 气质 |
|-----|------|------|
| cool | 冷蓝灰 | 克制学术工具 |
| paper | 暖纸感 | 米白笔记页（默认） |
| dark | 深色护眼 | 长时间阅读 |

存储键：`science-paper-assistant:theme`

## 验收

1. 三主题可切换且刷新后保持
2. 主流程可用：浏览、编辑、导入、导出、质量检查
3. 顶栏不再一排全挤；列表与中区更疏朗
4. 不引入新功能交互
