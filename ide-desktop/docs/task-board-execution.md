# 任务板暂停、验证与继续

任务板中的“暂停”会停止当前模型请求或验证命令，并保留已经完成的任务和文件操作。当前未完成任务返回待处理状态，整个任务板进入暂停状态；点击“继续执行”后，从该任务重新执行，依赖它的任务随后运行。

## 状态含义

| 场景 | 当前任务 | 任务板运行状态 | 后续行为 |
| --- | --- | --- | --- |
| 模型或工具执行中暂停 | 待处理 | 已暂停 | 明确继续后重跑当前任务 |
| 验证命令执行中暂停 | 待处理 | 已暂停 | 回收验证进程及所属子进程，不进入自动修复 |
| 一次修复期间暂停 | 待处理 | 已暂停 | 保留此前输出，不把取消报告为 blocked |
| 验证失败且修复未通过 | 阻塞 | 已暂停 | 显示真实失败原因，等待进一步处理 |
| 所有任务完成 | 已完成 | 空闲 | 不再显示执行中的暂停控件 |

暂停会清理任务的运行租约，避免下次恢复把已经结束的工作看成仍在执行。Git 保护单元在验证结束后记录最终结果；取消会记录为 cancelled，不会先记录成功再覆盖。无 Git 的工作区会跳过提交预览。

## 多会话与恢复

任务板操作明确携带当前会话 ID。即使另一个会话已经连接，暂停和继续也只作用于当前任务板。重新打开聊天或刷新界面时，会从现有桥接快照或保存的任务板恢复状态；暂停中的任务不会自动继续。

暂停后的计划保留当前任务标记和已完成任务的结果。聊天历史用简短任务标题显示内部执行轮次，完整执行提示和专家规则仍用于模型上下文。显示文字使用可选 `displayText` 字段；旧会话没有该字段时保持兼容，不批量改写历史文件。

## 验证命令

验证按项目现有的 `typecheck`、`test`、`build` 脚本依次执行。命令通过现有进程沙箱运行，取消信号会停止当前进程树；后面的验证命令不再启动。没有这些脚本时会返回跳过信息，项目仍需要自己的验收依据。

缺少脚本和项目配置损坏是不同结果：没有 `package.json` 或没有对应脚本时标为“验证未执行”；JSON 无效、脚本字段类型错误或配置无法读取时标为配置验证失败。禁用验证也只记录为跳过，不会附加“已验证”标记。

任务展开后可查看“验证记录”。每轮保留任务验证 / 修复后验证阶段、状态、起止时间，以及各命令的状态、退出码、耗时、输出与失败原因。一次修复成功后，最初失败的输出仍保留；重新打开会话可继续查看。验证中断也保存已经收到的部分输出。每条命令输出最多保存 12000 字符，超过时附带截断说明。

修复后必须重新通过此前失败的检查。只删除失败脚本、禁用检查，或运行另一条无关的成功脚本，不会把任务改为验证通过；任务保持阻塞并显示“验证不完整”。连续失败只进行既有的一次修复，随后保留记录，等待进一步处理。

旧任务没有保存验证记录时显示“验证未记录”，不从历史结果里的文字推断通过状态。记录中出现错误格式时界面跳过无效部分，不执行日志内容。

执行时只读专家保留只读工具边界，动态注入不会重新放行写入或派生权限。任务结束后恢复主会话的工具集、作用域和取消处理，避免影响下一轮普通聊天。

## 本地验证入口

- CLI 的 `tests/task-cancellation.test.ts`：模型取消、验证取消、修复取消、继续当前任务、专家权限恢复、真实 npm 子进程回收，以及 Git 保护结果只结束一次。
- CLI 的 `tests/task-board-pause-bridge.test.ts`：执行中接收暂停消息、返回一次 cancelled、恢复任务板后继续执行。
- CLI 的 `tests/task-verification-evidence.test.ts`：缺少检查、禁用检查、配置错误、失败脚本被删除、修复前后输出保留、持续失败次数限制和真实取消输出。
- `npm run test:app-tasks-ui`：正式构建 App 的双会话、真实 HTTP 接口夹具、真实 npm 验证进程、暂停后刷新及继续依赖任务。
- 上述 App 流程另含无测试、一次修复通过和持续失败三种场景；核对真实命令输出已保存，并在刷新后仍可展开阅读。
- `npm run test:app-workflows`：在已有 Git 阅读、写入、同步、后台应用和消息取消流程后，加入任务板验证。

报告与日志保存在 `out/task-board-*.log`、`out/task-board-review/result.json` 和 `out/app-review/results.json`。截图包含 `task-board-verification-paused.png`、`task-board-paused-reload.png`、`task-board-resumed-complete.png`。模型请求使用本地接口夹具，不等同远程付费模型的在线验收。
