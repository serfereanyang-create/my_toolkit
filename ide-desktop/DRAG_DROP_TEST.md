# 文件拖放功能测试指南

## 启动应用
```bash
npm run dev
```
应用将在 http://127.0.0.1:5176/ 启动

## 测试步骤

### 1. 基础拖放测试
- [ ] 从文件管理器拖动一个图片文件（.png/.jpg）到 Composer 输入框
- [ ] 应该看到蓝色拖放边框高亮
- [ ] 释放后应该出现文件预览卡片，显示：
  - 文件图标 🖼️
  - 文件名
  - 文件大小
  - 移除按钮 ×

### 2. 格式识别测试
测试不同文件类型是否正确识别：

| 文件类型 | 扩展名示例 | 预期图标 | 预期分类 |
|---------|----------|---------|---------|
| 图片 | .png, .jpg, .gif | 🖼️ | image |
| 文档 | .pdf, .docx, .txt | 📄 | document |
| 代码 | .js, .ts, .py | 💻 | code |
| 数据 | .json, .csv, .xml | 📊 | data |
| 压缩 | .zip, .tar, .gz | 📦 | archive |
| 视频 | .mp4, .avi | 🎬 | video |
| 音频 | .mp3, .wav | 🎵 | audio |

### 3. 多文件测试
- [ ] 同时拖动 2-3 个文件
- [ ] 所有文件都应该显示预览卡片
- [ ] 达到 10 个文件限制后应该提示"最多只能选择 10 个文件"

### 4. 大文件测试
- [ ] 拖动一个超过 100MB 的文件
- [ ] 应该弹出警告："文件 xxx 过大（xxx MB），最大支持 100 MB"

### 5. 智能提示测试
拖放文件后，输入框应该自动填充智能提示：

| 场景 | 预期提示 |
|-----|---------|
| 1个图片 | "请帮我分析这张图片" |
| 多个图片 | "请帮我分析这些图片" |
| 1个文档 | "请帮我查看这个文档" |
| 混合文件 | "请帮我查看这些文件" |

### 6. 移除文件测试
- [ ] 点击文件卡片上的 × 按钮
- [ ] 文件应该从列表中移除
- [ ] 可以再次拖放新文件

### 7. 拖放视觉反馈测试
- [ ] 拖动文件到输入框上方时，边框变为蓝色虚线
- [ ] 拖动文件离开时，边框恢复正常
- [ ] 文件卡片有圆角和阴影

### 8. 发送测试
- [ ] 添加文件后点击发送
- [ ] 检查控制台，应该看到文件信息被传递
- [ ] 文件路径应该正确（Electron 的 file.path）

## 预期功能清单
✅ 拖放区域高亮反馈  
✅ 文件格式自动识别（8种分类）  
✅ 文件大小验证（最大100MB）  
✅ 文件数量限制（最多10个）  
✅ 文件预览卡片（图标、名称、大小、移除）  
✅ 智能提示生成  
✅ 文件移除功能  
✅ 文件路径传递到后端  

## 已知限制
- 最大文件大小：100 MB
- 最大文件数量：10 个
- 仅支持常见文件格式
