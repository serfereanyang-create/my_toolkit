feat(dispatch): three tiers with ordered model chains

- DispatchTier gains 'standard' (中档) between expensive and cheap, for
  ordinary feature work that needs judgement but not the top model
- Each tier now holds an ordered list: first entry is the primary, the rest
  are fallbacks used when the primary fails (rate limit / quota / auth).
  A bare string is still accepted so old selections keep working
- readGlobalDispatchDefault no longer hardcodes the expensive/cheap pair --
  it was silently dropping any tier it didn't know about, which would have
  made the new 中档 unseen
- A qualified selector whose provider prefix no longer exists (stale desktop
  label) falls back to matching the model name alone instead of failing the
  whole tier
